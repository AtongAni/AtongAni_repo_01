## 🔧 Configuration Details

### Django Settings Added
```python
MEDIA_URL = 'media/'
MEDIA_ROOT = BASE_DIR / 'media'
```

### Image Validation
- **Formats**: JPEG, PNG, GIF, WebP
- **Max Size**: 5MB
- **Optional**: Yes (can post without image)

### Storage Location
- **Path**: `farmers-market/media/posts/`
- **Filename Format**: auto-generated by Django
- **Example**: `posts/filename_abc123.jpg`

## 🚨 Troubleshooting Guide

### "ModuleNotFoundError: No module named 'PIL'"
```bash
pip install Pillow==10.1.0
```

### "media folder not found"
```bash
# Django creates it automatically on first upload
# Or manually create:
mkdir farmers-market/media
```

### "Images not showing in posts"
- Check MEDIA_URL in settings (should be `'media/'`)
- Check URL pattern in config/urls.py
- Verify Django dev server is running
- Check browser console for 404 errors

### "Upload fails with validation error"
- Check file format (JPEG, PNG, GIF, WebP only)
- Check file size (must be < 5MB)
- Check Django logs for detailed error

### "Database migration fails"
```bash
# Check migration status
python manage.py showmigrations posts

# If stuck, you may need to:
python manage.py migrate posts --fake 0002_post_quantity_post_unit
python manage.py migrate posts
```

## 📝 API Documentation

### Create Post with Image
```
POST /api/posts/
Content-Type: multipart/form-data

Request:
{
  "title": "Fresh Tomatoes",
  "content": "Organic tomatoes...",
  "price": "50.00",
  "quantity": "100",
  "unit": "KG",
  "image": <file>

{

  "title": "Fresh Tomatoes",
  "content": "Organic tomatoes...",
  "image": "posts/abc123.jpg",
  "image_url": "http://localhost:8000/media/posts/abc123.jpg",
  "price": "50.00",
  "quantity": "100.00",
  "unit": "KG"
}
```
